# ITC 320 Web Application Development – Client-Side Scripting

## VS Code Setup and Usage Instructions for Students

### Course Overview

In this course, you will use **Visual Studio Code (VS Code)** to develop and test client-side web applications. You will work primarily with:

* **HTML**: Structure and content of web pages
* **CSS**: Styling and layout
* **JavaScript**: Client-side programming and interactivity
* **DOM (Document Object Model)**: Manipulating web page elements with JavaScript
* **Browser Developer Tools**:Testing and debugging your applications

You are expected to become comfortable creating, organizing, running, and debugging web projects using VS Code.

---

## Install Visual Studio Code

Download and install **Visual Studio Code** from the official website:

**https://code.visualstudio.com/**


After installation, open VS Code to verify that it starts successfully.

---

## Create a Workspace for the Course

Create a folder on your computer where you will keep all of your course work.

For example:

```text
ITC320/
```

Inside this folder, create a separate folder for each week:

```text
ITC320/
│
├── Week_1/
├── Week_2/
├── Assignment_1/
├── Assignment_2/
└── Project/
```
Feel free to organize it in a way you feel comfortable. The above folder structure is only for your understanding.

---

## Open Your Project in VS Code

1. Open **VS Code**.
2. Select **File → Open Folder**.
3. Select your course folder or the folder for the assignment you are working on.
4. Click **Select Folder**.

Your project files will appear in the **Explorer** panel on the left side of VS Code.

### Recommended approach

Open the **specific week folder** rather than opening your entire computer or Downloads folder.

---

## Run Your Web Application

The simplest way to test a web page is to open the HTML file in a web browser.

You can:

1. Locate `index.html` in VS Code.
2. Right-click the file.
3. Select **Reveal in File Explorer/Finder**.
4. Open the HTML file in your browser.

---

## Save Your Work Frequently

Save your files regularly.

Use:

* **Windows:** `Ctrl + S`
* **Mac:** `Cmd + S`

Before testing your application, make sure your files are saved.

It is good practice to save your work whenever you complete a significant change.

---

## Debug JavaScript Using the Browser

When your JavaScript does not work as expected, use your browser's **Developer Tools**.

In most browsers, you can open Developer Tools by:

* Right-clicking the web page and selecting **Inspect**
* Or using the browser's Developer Tools keyboard shortcut (`F12`)
